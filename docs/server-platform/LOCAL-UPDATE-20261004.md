## Изменения интерфейса и API

1. Список замесов открывает последнюю доступную дату, если дата не указана в URL и за сегодняшний день записей нет. Если пользователь выбрал дату явно, она сохраняется. Для этого добавлен `GET /api/batches/latest-date` с датой хозяйства.
2. На телефоне список замесов и карточка компонентов внутри замеса помещаются в ширину экрана без горизонтальной прокрутки. Длинные названия переносятся; значки состояния располагаются отдельной строкой; кнопка удаления остаётся компактной.
3. Значки проверки веса, GPS и нарушений в списке и деталях стали кнопками. Нажатие открывает пояснение, повторное нажатие закрывает его. На узком экране пояснение показывается поверх нижней части экрана и не обрезается карточкой.
4. В деталях замеса без назначенного рациона убрана непонятная кнопка «Переименовать». Вместо неё показано название компонента и пояснение об отсутствии рациона. Выбор замены компонента при назначенном рационе остаётся.
5. Из админки телеметрии удалены блоки «Последняя SMS» и «SMS и входящие звонки за месяц», а также их загрузка и очистка на клиенте. Серверный `/api/events` не удалён для совместимости.
6. Под картой главной страницы появился блок «Планшет». Для каждого зарегистрированного планшета он показывает свежесть связи, версию и активное задание. Во время загрузки показывает группу, рацион, шаг, вес и шкалу текущего компонента. Шкала использует свежий вес HOST относительно сохранённой базы шага; вес старше 15 секунд не считается текущим. Без задания показывается пустое состояние. Данные читаются через `GET /api/loader/dashboard`, обновление при видимой вкладке — раз в 5 секунд. Ключи доступа и удалённые команды в ответ не включены.
