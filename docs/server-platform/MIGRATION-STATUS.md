## Ограничения эксплуатации

Один расчётный процесс на БД; второй блокируется advisory lock. Общий бюджет текущего процесса: Prisma API 12 + расчёт 4, pg API 6 + worker 2 (до 24 соединений), PG max_connections 50. При добавлении хозяйств бюджеты необходимо пересчитать; нельзя просто запустить три одинаковых процесса с этими лимитами.

Единственный VPS не обеспечивает HA. Автоматической внешней копии и PITR нет; внешние копии пока выполняются вручную. 20 устройств по 1 Гц дают 1 728 000 пакетов в сутки: перед полным подключением такого количества нужны измерение реального роста данных и увеличение диска либо согласованное архивирование. Raw retention оставлен выключенным по прежним требованиям. Бесконечная история на текущем диске не гарантируется.

Инструкция эксплуатации и граница отката: OPERATIONS.md. После нового PG ACK нельзя возвращать старые SQLite очереди или старый dump поверх рабочей базы: это потеряет новые подтверждённые данные.
