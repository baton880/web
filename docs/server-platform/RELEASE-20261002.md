# Realtime-замесы — кандидат выпуска 2 октября 2026

Этот документ описывает состав проверенного Git-релиза до production-переключения. Фактический путь выпуска, commit, backup и результаты публичной проверки фиксируются отдельной записью `DEPLOY-20261002.md` после развёртывания.

## Поведение

- Новые замесы рассчитываются в realtime старым `TelemetryProcessor`, включая пересечение loading/barn. Завершение и API-чтение не запускают заменяющую факты постобработку.
- События планшета сразу сохраняют подтверждённый компонент. HOST независимо рассчитывает вес и определяет компонент по GPS; RTK используется как дополнительное, но необязательное свидетельство.
- Допуск алгоритм↔планшет настраивается в ADMIN, по умолчанию: строго меньше 5% либо не больше 5 кг. При согласии рабочим становится алгоритмический вес; планшетный факт сохраняется отдельно.
- Бизнес-порог отклонения от плана остаётся строго больше 10%. Красные нарушения: планшетное отклонение, пропуск, лишний/неизвестный компонент, порядок и остаток. Жёлтые: только алгоритмическое отклонение или устойчиво другое GPS-название.
- Проезд через соседнюю зону до `confirm` не считается вторым компонентом. Для соломы/люцерны без надёжного положения погрузчика планшет служит подсказкой с низкой уверенностью.
- В списке и карточке веса, порядок и уверенность имеют отдельные пиктограммы с tooltip. График показывает начало и конец каждого связанного планшетного шага. В деталях рядом с принятым весом показан отличающийся вес второго источника.
- Отчёты используют рабочий realtime-вес, связывают нарушения с датой замеса и различают активные/закрытые записи.

## Схема и конфигурация

Добавочные PostgreSQL migrations:

1. `20261001000200_realtime_batch_mode` — `Batch.processingMode` с безопасным default `legacy`;
2. `20261002000100_realtime_weight_tolerance_settings` — два ADMIN-допуска со значениями 5/5.

Для production задать:

```text
BATCH_PROCESSING_MODE=realtime
REALTIME_RTK_MODE=auto
```

Существующие строки остаются `legacy`; автоматический replay и backfill истории не входят в развёртывание. Raspberry Pi, протокол устройств, APK, raw retention и RTK replay не меняются.
